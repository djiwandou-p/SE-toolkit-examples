# ResepKu

> Aplikasi resep masakan sederhana untuk membantu pengguna menemukan, menyimpan, dan mengelola resep favorit.

## Description

ResepKu adalah aplikasi yang membantu pengguna menyimpan resep masakan favorit dan mencari resep berdasarkan bahan yang tersedia di rumah. Aplikasi ini ditujukan untuk pelajar, pemula dalam memasak, serta siapa pun yang ingin mengatur resep agar tidak lagi tersimpan secara acak di catatan ponsel. Dengan ResepKu, pengguna dapat menemukan ide masakan dengan lebih cepat dan mengikuti langkah memasak secara teratur.

## Features

- Menambahkan resep baru beserta bahan dan langkah memasak
- Mencari resep berdasarkan nama masakan atau bahan utama
- Menyimpan resep favorit ke dalam daftar koleksi pribadi
- Menandai resep yang sudah pernah dicoba
- Melihat detail resep, termasuk bahan, langkah, dan estimasi waktu memasak

## Installation

```bash
# Clone repository proyek
git clone [https://github.com/djiwandou-p/resepku.git](https://github.com/djiwandou-p/resepku.git)

# Masuk ke folder proyek
cd resepku

# Install dependencies
pip install -r requirements.txt

# Jalankan aplikasi
python app.py
```

## Usage

Setelah aplikasi berjalan, pengguna dapat membuka aplikasi melalui browser atau antarmuka yang tersedia. Pengguna dapat menekan tombol **Tambah Resep** untuk memasukkan nama masakan, bahan, langkah memasak, dan estimasi waktu. Pengguna juga dapat menggunakan kolom pencarian untuk menemukan resep berdasarkan nama masakan atau bahan, lalu menekan tombol **Simpan ke Favorit** agar resep mudah ditemukan kembali.
